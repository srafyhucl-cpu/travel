# 小程序 Logo（144×144 PNG）设计稿

日期：2026-10-08
状态：已与用户逐轮确认（方向 → 底色 → 细节 → 生成方式）

## 目的

给「旅行助手」微信小程序一个 144×144 的 PNG logo，主要用作小程序头像
（微信端会被裁成圆形显示），也可用于分享图、页面占位。

## 定稿方案

- **尺寸/格式**：144×144，PNG（带 alpha 通道）
- **底**：`#F4F5F7` 圆角方块，`rx=32`，四角为透明
  - 已验证：直径 144 的内切圆完全落在 rx=32 的圆角矩形内，
    所以微信裁圆后不会露出缺角
- **主体**：一条从左下蜿蜒到右上的「路线丝带」+ 终点图钉
  - 丝带：15px 线宽、圆头，线性渐变 `#2F80ED → #12D6B6`（左下 → 右上）
  - 图钉：实心 `#111827`，中心 6.5r 的 `#fff` 挖空
  - 不加起点标记、不加途经点、不加文字（用户选择「基准版」，且确认不放字）
- **构图**：整组图形统一 `translate(-4, 6)` 居中，四周留白约 15–22px
- **配色依据**：主色取自 `miniprogram/app.wxss` 的 `--accent: #2f80ed`，
  背景取 `--bg: #f4f5f7`，图钉取 `--ink: #111827`

## 交付物

| 文件 | 说明 |
| --- | --- |
| `tools/logo/logo.svg` | 矢量源文件，后续改色/改形都从这里改 |
| `tools/logo/render.mjs` | 渲染脚本（@resvg/resvg-js） |
| `tools/logo/dist/logo-144.png` | 主交付物，144×144 |
| `tools/logo/dist/logo-576.png` | 4 倍高清版（288/576 一并导出），供印刷或网页用 |

## 实现方式

用户选定 **resvg**：`npm i @resvg/resvg-js`（registry：npmmirror），
脚本读 `logo.svg`，用 `fitTo: { mode: 'width', value: N }` 按需缩放导出。

不引入其它依赖，不改动 `web/`、`miniprogram/` 的现有代码。

## 验收

1. `logo-144.png` 的 IHDR 宽高 = 144×144（脚本内断言，不满足则报错）
2. 肉眼检查：丝带完整、图钉未被裁切、底色为 `#F4F5F7`
3. 48px 缩略下仍能辨认出「路线 + 终点」
